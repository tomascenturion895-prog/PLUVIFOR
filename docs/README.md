# docs

Documentación del proyecto. Cada archivo tiene un responsable y se mantiene junto con el código que describe.

| Documento | Para qué sirve |
|---|---|
| `CONTRIBUTING.md` | Cómo trabajamos: ramas, commits, Pull Requests y Definition of Done. |
| `ENTORNO.md` | Cómo dejar la computadora lista para trabajar en el proyecto. |
| `modelo-datos.md` | Modelo de datos y reglas que impiden que un hueco se guarde como 0 mm. |
| `seguridad-secretos.md` | Política de secretos y cómo se escanean. |
| `datos/` | Datos de ejemplo, catálogo de estaciones y originales de cada fuente. |
| `qa/` | Plan de pruebas y casos de prueba. |

Algunos de estos archivos se agregan con tareas posteriores del tablero.
